\subsection{Finding skyrmions}

Wee know that a characteristic if a skyrmionn is a localized wrapping number. This then becomes something we can detect. To do this first we smooth (example shown in figure~\ref{fig: smooth}), using a Gaussian convolution, to get ride of fluctuations.

\begin{figure}[H]
	\centering
	\includegraphics[width = \linewidth]{sections/Graphs/smoothed.png}
	\caption{An example of the wrapping number calculated from the spin lattice}
	\label{fig: smooth}
\end{figure}

On this smoothed results a positive skyrmion will have a positive localized wrapping number, while a negative Skyrmion has a negative localized wrapping number. To find the maxima and minima, we look in a 5 by 5 square centered around each point and check if the middle point is higher or lower than all its neighbours. A result from the maxima finding algorithem is shown in figure~\ref{fig: max min}

\begin{figure}[H]
	\centering
	\includegraphics[width = \linewidth]{sections/Graphs/detection.png}
	\caption{An example of the wrapping number calculated from the spin lattice}
	\label{fig: max min}
\end{figure}

Now that we have found the maxima and minima we need to see if they are actually skyrmions and not just thermal fluctuations. 

Summing the wrapping number over the whole grid we get the Q-number which is some integer describing the number of positive skyrmions minus the numer of negative skyrmions. From this we know how many peaks we need to find. This is done by getting value of the lowest minima or highest maxima found and checking down from there adding keep adding peaks untill we find the Q-number.

\subsection{Distinguishing phases}

there are a few phases to be found here, one where the ferromagnetic interaction dominates, one where the DM interaction dominates (spiral phase), and then one where skyrmions can be found.

To distinguish ferromagnetic from the spiral phase one can simply look at the average magnetization in the Z-direction. This is because the H field is applied in the z direction meaning that the ferromagnetic phase would like to point in that direction, while the DM interaction prefers spins point into the x,y-plane. Meaning that in the ferromagnetic domain the average magnetization will be close to 1 in the z direction while in the spiral phase it will be close to 0.
